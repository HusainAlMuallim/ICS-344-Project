# Source Area

Use this directory if you later pull the DVSA source locally or export patched files from AWS for cleaner code/config diffs.

Suggested use:
- keep the original upstream DVSA source in a subdirectory
- keep your patched copy in a separate subdirectory or branch
- reference exact files from `fixes/lesson-XX/` and the report

Do not place active secrets, tokens, or AWS credential files here.
