# Submission Checklist

## Required Deliverables

- Written report in PDF format
- Presentation slides in PDF or PowerPoint format
- GitHub repository link
- Demo video recording

## Report Checklist

- Cover page completed
- All 10 official lessons included
- Every lesson uses Parts 1 through 10
- Table A and Table B included for every lesson
- Pre-fix evidence is readable
- Fix is concrete and technically relevant
- Post-fix verification is present
- Real secrets are redacted

## Repository Checklist

- README explains repo structure and reproduction path
- Evidence is organized by lesson
- Fixes are stored cleanly
- Helper scripts are documented
- Sensitive raw files are excluded or sanitized

## Slides / Demo Checklist

- Terminology matches the report
- Each lesson shows exploit, proof, patch, and verification
- Slides emphasize the strongest evidence instead of every small detail
