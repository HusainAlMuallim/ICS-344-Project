# Report

The main deliverable. `report-template.tex` contains the full LaTeX report with all 10 lessons.

**Compile:**
```bash
pdflatex report-template.tex
pdflatex report-template.tex   # run twice for TOC
```

Each lesson follows the mandatory 10-part structure (see `project-guide.tex` for details).
Evidence images are referenced from `../evidence/lesson-XX/`.
